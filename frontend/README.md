
# Memepedia Frontend

Клиентская часть платформы Memepedia.

## Технологии

- React
- TypeScript
- Vite
- CSS

## Требования

- Node.js 22 или совместимая версия
- npm

## Установка

Перейти в папку frontend:

cd frontend

Установить зависимости:

npm install

## Запуск разработки

npm run dev

После запуска открыть адрес,
который выведет Vite.

## Проверка сборки

npm run build

## Реализованные возможности

- Главная страница Memepedia
- Адаптивная сетка карточек
- Демонстрационные данные мемов
- Поиск по названию
- Лайки в состоянии React

## Ограничения

- Серверный API ещё не подключён.
- Публикация мемов пока недоступна.
- Данные хранятся только в памяти приложения.
