
# Memepedia — UI-kit

## Назначение

UI-kit содержит описание визуального оформления
веб-платформы Memepedia.

## Цветовая палитра

- Primary: #6366F1
- Primary Hover: #4F46E5
- Background: #F8FAFC
- Surface: #FFFFFF
- Text: #0F172A
- Secondary Text: #64748B
- Border: #E2E8F0
- Error: #DC2626
- Success: #16A34A

## Типографика

Основной шрифт: Arial, sans-serif.

- H1: 32px, Bold
- H2: 24px, Bold
- H3: 20px, Bold
- Основной текст: 16px
- Дополнительный текст: 14px
- Подписи: 12px

## Отступы

Базовый шаг отступов — 8px.

Допустимые значения:
8px, 16px, 24px, 32px, 48px.

## Компоненты

### Кнопка

Варианты:
- Primary
- Secondary
- Disabled

Состояния:
- Default
- Hover
- Focus
- Disabled

### Поле ввода

Варианты:
- Username
- Email
- Password
- Search

### Карточка мема

Содержит:
- Область изображения
- Название
- Автора
- Количество лайков
- Количество комментариев

### Шапка сайта

Содержит:
- Логотип Memepedia
- Поиск
- Кнопку публикации
- Переход в профиль

## Страницы приложения

1. Главная страница
2. Регистрация
3. Авторизация
4. Профиль пользователя
5. Просмотр мема
6. Создание публикации

## Адаптивность

- Мобильная версия: до 767px
- Планшеты: 768–1023px
- Десктоп: от 1024px


## Проверка UI-kit

В рамках учебной симуляции проведена
проверка подготовленных интерфейсов.

Проверены:
- Соответствие прототипа цветовой палитре
- Согласованность типографики
- Структура карточек мемов
- Адаптивность основных блоков
- Наличие базовых компонентов интерфейса

Результат проектирования подготовлен
для передачи на проверку.


## Итоги согласования

Статус: согласовано в рамках учебной симуляции.

Документация UI-kit и прототип главной
страницы приняты для дальнейшей разработки.

Изменения объединены с веткой develop.

Связанная задача: MEM-5.
