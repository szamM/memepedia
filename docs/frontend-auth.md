
# Frontend авторизации Memepedia

## 1. Общая информация

- Проект: Memepedia
- Задача: MEM-13
- Спринт: Sprint 2
- Исполнитель: Frontend Developer
- Статус: Завершено в рамках учебной симуляции

## 2. Реализованные функции

### Страница входа

Маршрут: /login

Реализовано:
- Поле email.
- Поле пароля.
- Клиентская проверка данных.
- Отправка запроса к API.
- Состояние загрузки.
- Отображение ошибок.
- Переход на страницу регистрации.

### Страница регистрации

Маршрут: /register

Реализовано:
- Поле имени пользователя.
- Поле email.
- Поле пароля.
- Подтверждение пароля.
- Проверка обязательных полей.
- Проверка формата email.
- Проверка длины пароля.
- Проверка совпадения паролей.
- Отображение ошибок.
- Переход на страницу входа.

## 3. API

Frontend использует следующие маршруты:

- POST /api/auth/register
- POST /api/auth/login
- GET /api/auth/me
- POST /api/auth/logout

Отправка запросов выполняется через fetch.

Для cookie используется credentials: include.

## 4. Маршрутизация

React Router обрабатывает:

- / — главная страница.
- /login — вход.
- /register — регистрация.

## 5. Локальное окружение

Frontend: localhost:5173

Backend: localhost:3001

Vite перенаправляет запросы с /api
на Backend через proxy.

## 6. Реализованная обработка состояний

- Отправка формы.
- Ожидание ответа сервера.
- Успешный ответ.
- Ошибка валидации.
- Ошибка сервера.
- Ошибка подключения.

## 7. Проверка

Запланированы проверки:

1. Сборка проекта.
2. Отображение страницы входа.
3. Отображение страницы регистрации.
4. Переходы между страницами.
5. Проверка пустых полей.
6. Проверка email.
7. Проверка длины пароля.
8. Проверка совпадения паролей.
9. Адаптивность интерфейсов.

## 8. Ограничения

Backend API реализуется в MEM-14.

До завершения MEM-14 невозможно
выполнить полноценную проверку
успешной регистрации и авторизации.

Текущая реализация содержит
клиентскую часть интеграции.

## 9. Критерии завершения

- Реализованы React-страницы.
- Настроена маршрутизация.
- Подключён клиент API.
- Реализована клиентская валидация.
- Подготовлены стили.
- Выполнена доступная локальная проверка.
- Изменения переданы на Review.


## 10. Итоги разработки

Frontend регистрации и авторизации
подготовлен к интеграции с Backend API.

Реализованы:
- Маршрутизация.
- Формы входа и регистрации.
- Клиентская валидация.
- Обработка ответов сервера.
- Обработка ошибок.
- Адаптивный интерфейс.

Изменения рассмотрены в Pull Request
и объединены с веткой develop.

Полная интеграционная проверка
будет проведена в MEM-14 и MEM-15.
