## Sprint 3

### MEM-19 — Frontend профиля и поиска

Подготовлено описание пользовательского
интерфейса профиля и поиска мемов.

Страница профиля должна содержать:
- Имя пользователя.
- Электронную почту.
- Ссылку на главную страницу.

Поиск мемов должен поддерживать:
- Ввод названия мема.
- Отображение найденных результатов.
- Сообщение при отсутствии результатов.

В существующем прототипе уже есть
локальный поиск мемов и авторизация.

Результат учебного этапа:
описаны требования к интерфейсу
и основные пользовательские сценарии.

Реализация дополнительных функций
в коде не входит в этот этап симуляции.


Проверка документации:
описание профиля и поиска соответствует
требованиям, подготовленным в MEM-18.

Статус артефакта: готов к проверке.

Статус учебного этапа: завершён.
Текстовая документация объединена с develop.


### MEM-20 — Backend профиля и поиска

Цель задачи:
Спроектировать серверные функции
просмотра профиля и поиска мемов.

Предусмотрены следующие API:

1. GET /api/auth/me
   Получение информации об авторизованном
   пользователе: имени и электронной почты.

2. GET /api/memes?q=текст
   Поиск мемов по названию.

Ожидаемые результаты:
- При успешном поиске возвращается список мемов.
- При отсутствии совпадений возвращается пустой список.
- Неавторизованный пользователь не получает
  персональные данные другого пользователя.
- При ошибке сервер возвращает соответствующий
  HTTP-статус.

Результат учебного этапа:
Подготовлено описание серверного API.

Реализация поиска в коде не выполнялась.
