
# Memepedia — окружение разработки

## Структура проекта

- frontend — React + TypeScript
- backend — Node.js + Express
- database — PostgreSQL

## Git-стратегия

- main — стабильные версии
- develop — интеграционная ветка
- feature/MEM-XX — ветки задач

## Правила разработки

1. Для каждой задачи создаётся отдельная ветка.
2. Коммиты содержат идентификатор задачи.
3. Изменения отправляются через Pull Request.
4. После проверки изменения объединяются с develop.

## Проверка окружения

- Проверена структура репозитория.
- Подготовлена документация по настройке окружения.
- Определён порядок работы с Git-ветками.
- Проверено подключение GitHub к YouTrack.
