
# Требования к третьему спринту Memepedia

## 1. Общая информация

- Проект: Memepedia
- Спринт: Sprint 3
- Задача: MEM-18
- Исполнитель: Project Manager
- Статус: В разработке

## 2. Цель

Добавить в Memepedia две функции:

1. Просмотр профиля пользователя.
2. Поиск мемов через серверный API.

## 3. Профиль пользователя

Авторизованный пользователь должен
иметь возможность открыть страницу /profile.

На странице отображаются:
- Имя пользователя.
- Электронная почта.
- Ссылка на главную страницу.

Данные пользователя получаются через
существующий API:

GET /api/auth/me

Неавторизованный пользователь
не должен видеть данные профиля.

## 4. Поиск мемов

Пользователь должен иметь возможность
искать мемы по названию.

Для поиска используется API:

GET /api/memes?q=текст

Backend возвращает JSON-массив мемов.

Формат одного мема:
- id
- title
- author
- emoji
- likes
- comments

Если совпадений нет, возвращается
пустой массив.

Для учебного MVP допускается
использование небольшого набора
демонстрационных мемов на сервере.

## 5. Ограничения

В рамках этого спринта не реализуем:
- Редактирование профиля.
- Загрузку аватара.
- Изменение пароля.
- Сложные фильтры поиска.
- Пагинацию.
- Полнотекстовый поиск.
- Загрузку изображений на сервер.

## 6. Распределение работ

MEM-19 — Frontend профиля и поиска.

MEM-20 — Backend поиска и данных профиля.

MEM-21 — Интеграционное тестирование.

MEM-22 — Подготовка staging-окружения.
