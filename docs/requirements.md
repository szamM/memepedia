
# Функциональные требования Memepedia

## 1. Назначение системы

Memepedia — веб-платформа для публикации,
просмотра и обсуждения мемов.

## 2. Пользовательские роли

- Гость — просмотр публичных материалов.
- Пользователь — публикация и обсуждение мемов.
- Администратор — модерация контента и пользователей.

## 3. Функциональные требования

### FR-01. Регистрация
Система должна позволять пользователю
создавать учётную запись.

### FR-02. Авторизация
Система должна поддерживать вход и выход
из учётной записи.

### FR-03. Публикация мемов
Пользователь должен иметь возможность
загружать изображения с названием и описанием.

### FR-04. Просмотр мемов
Система должна отображать ленту публикаций.

### FR-05. Поиск
Система должна предоставлять поиск мемов
по названию.

### FR-06. Комментарии
Авторизованные пользователи должны иметь
возможность комментировать публикации.

### FR-07. Оценка публикаций
Пользователь должен иметь возможность
ставить и удалять отметку «Нравится».

### FR-08. Профиль пользователя
Пользователь должен иметь личный профиль
со списком своих публикаций.

## 4. Нефункциональные требования

- Адаптивный интерфейс.
- Защищённое хранение паролей.
- Валидация пользовательских данных.
- Обработка ошибок приложения.

## 5. Критерии приёмки

- Основные пользовательские сценарии описаны.
- Функциональные требования пронумерованы.
- Пользовательские роли определены.
- Документ доступен в Git-репозитории.
