
# Отчёт о тестировании авторизации Memepedia

## 1. Общая информация

- Проект: Memepedia
- Задача: MEM-15
- Исполнитель: QA Engineer
- Спринт: Sprint 2
- Статус: На проверке

## 2. Цель

Проверить функциональность регистрации,
авторизации, выхода из системы
и обработки некорректных данных.

## 3. Тестовое окружение

- Frontend: React, TypeScript, Vite
- Backend: Express, TypeScript
- База данных: PostgreSQL 18
- Инструмент: Playwright
- Браузер: Chromium

## 4. Автоматизированные сценарии

1. Отображение главной страницы и навигация.
2. Валидация пустых полей входа.
3. Проверка несовпадающих паролей.
4. Регистрация, вход и выход пользователя.
5. Проверка минимальной длины имени.

## 5. Команды запуска

Из папки frontend:

npm run test:e2e

Просмотр HTML-отчёта:

npx playwright show-report

## 6. Результаты

Количество автоматизированных тестов: 5.

Фактические результаты: 5 тестов пройдено

## 7. Управление дефектами

Обнаруженные ошибки фиксируются
в GitHub Issues.

Исправления проверяются повторным
запуском соответствующих тестов.

Результаты исправлений фиксируются
в истории Git-коммитов.

## 8. Критерии завершения

- Подготовлены автоматизированные тесты.
- Выполнен тестовый прогон.
- Зафиксированы результаты.
- Обнаруженные дефекты зарегистрированы.
- Выполнена повторная проверка исправлений.
- Документация передана на Review.
